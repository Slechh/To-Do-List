# Todo List

Минималистичное приложение для управления задачами с поддержкой тёмной темы.

## Стек

- **React 19** + **TypeScript**
- **Tailwind CSS** + **clsx**
- **Zustand** — стейт менеджмент и хранение темы
- **Sonner** — toast-уведомления
- **Vite**

## Возможности

- Создание, редактирование и удаление заметок
- Отмена удаления через undo
- Фильтрация по статусу — все, выполненные, невыполненные
- Поиск по заметкам
- Тёмная и светлая тема с сохранением в localStorage
- Клавиатурные шорткаты — Enter для подтверждения, Escape для закрытия

## Запуск

```bash
git clone https://github.com/Slechh/To-Do-List.git
cd To-Do-List
npm install
npm run dev
```

## Скрипты

| Команда | Описание |
|---|---|
| `npm run dev` | Запуск dev-сервера |
| `npm run build` | Сборка проекта |
